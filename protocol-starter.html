Как байт выглядит на проводеWhat a byte looks like on the wire

UART 115200 8N1 · 0x55 'U'1 бит = 8,68 мкс · байт = 86,8 мкс1 bit = 8.68 µs · byte = 86.8 µs
Байт:Byte:

Линия в покое — единица. Стартовый бит опускает её в ноль, дальше 8 бит данных младшим вперёд, стоповый бит возвращает в единицу. У 0x55 перепад в каждой ячейке, поэтому по нему проще всего проверить скорость на экране.An idle line is high. The start bit pulls it low, then 8 data bits go out least significant first, and the stop bit returns the line high. 0x55 has an edge in every cell, which makes it the easiest byte for checking the baud rate on screen.

M8 Нет сброса после ошибки длиныNo flush after a length error восстановление после мусораrecovery after junk caught · выжил в 1-м раунде· survived round 1

M7 сначала ничего не менял: ответ на broadcast всё равно отсекала следующая проверка адреса. Такой мутант называется эквивалентным, его переписали. M8 выжил, потому что после плохого заголовка тест ничего не присылал. Теперь он шлёт байты, похожие на начало следующего кадра, и устройство без сброса проглатывает следующий запрос.M7 first changed nothing: the following address check still blocked the broadcast reply. That is an equivalent mutant, so it was rewritten. M8 survived because the test sent nothing after the bad header. It now sends bytes that look like the start of the next frame, and a device without the flush swallows the next request.

ТерминыGlossary

UART, 8N1
Последовательный порт. 8N1 — 8 бит данных, без чётности, 1 стоповый бит.Serial port. 8N1 means 8 data bits, no parity, 1 stop bit.
БодBaud
Символов в секунду; у UART один символ — один бит. 115200 бод → 8,68 мкс на бит.Symbols per second; on UART one symbol is one bit. 115200 baud → 8.68 µs per bit.
Псевдотерминал (PTY)Pseudo-terminal (PTY)
Файл порта без железа; socat соединяет два таких конца.A port device with no hardware behind it; socat joins two ends.
Частота выборкиSample rate
Как часто анализатор меряет линию; нужно хотя бы в 4–10 раз чаще скорости сигнала.How often the analyzer reads the line; at least 4–10 times the signal rate.
CRC-16/MODBUS
Контрольная сумма кадра; на провод идёт младшим байтом вперёд: C4 0B.Frame checksum; sent low byte first: C4 0B.
Broadcast
Кадр на адрес 0: выполняют все, не отвечает никто.A frame to address 0: everyone executes it, nobody answers.
HIL
Hardware-in-the-loop: те же тесты на настоящем железе.Hardware-in-the-loop: the same tests on real hardware.
Эквивалентный мутантEquivalent mutant
Изменение кода, которое не меняет поведение, поэтому его не поймает ни один тест.A code change that does not change behaviour, so no test can catch it.
